def selection_rate(y_pred):
    # TODO: fraction of predictions that are positive (one line)
     return sum(y_pred) / len(y_pred) if len(y_pred) > 0 else 0
    

def tpr(y_true, y_pred):
    # TODO: positive class only — what fraction of true positives did we predict positive?
    actual_positives = [(t, p) for t, p in zip(y_true, y_pred) if t == 1]
    if not actual_positives:
        return 0
    return sum(1 for t, p in actual_positives if p == 1) / len(actual_positives)
    pass

def fpr(y_true, y_pred):
    # TODO: negative class only — what fraction of true negatives did we wrongly flip to 1?
    actual_negatives = [(t, p) for t, p in zip(y_true, y_pred) if t == 0]
    if not actual_negatives:
        return 0
    return sum(1 for t, p in actual_negatives if p == 1) / len(actual_negatives)
    pass

def audit_one_subgroup(df, subgroup_col, score_col='prediction', label_col='label'):
    groups = df[subgroup_col].unique()
    
    group_selection_rates = {}
    group_tprs = {}
    group_fprs = {}
    
    # 1. Calculate metrics for each subgroup
    for group in groups:
        subset = df[df[subgroup_col] == group]
        y_true = subset[label_col].tolist()
        y_pred = subset[score_col].tolist()
        
        group_selection_rates[group] = selection_rate(y_pred)
        group_tprs[group] = tpr(y_true, y_pred)
        group_fprs[group] = fpr(y_true, y_pred)
        
    # 2. Calculate differences and ratios
    # DP Ratio = min(selection_rate) / max(selection_rate)
    min_sr = min(group_selection_rates.values())
    max_sr = max(group_selection_rates.values())
    dp_ratio = min_sr / max_sr if max_sr > 0 else 1.0
    
    # EO Diff = max gap in EITHER TPR or FPR
    tpr_gap = max(group_tprs.values()) - min(group_tprs.values())
    fpr_gap = max(group_fprs.values()) - min(group_fprs.values())
    eo_diff = max(tpr_gap, fpr_gap)
    
    # EOpp Diff = max gap in TPR only
    eopp_diff = tpr_gap
    
    # Overall accuracy for this subgroup
    correct = sum(1 for t, p in zip(df[label_col], df[score_col]) if t == p)
    accuracy = correct / len(df)
    
    return {
        'dp_ratio': dp_ratio,
        'eo_diff': eo_diff,
        'eopp_diff': eopp_diff,
        'accuracy': accuracy
    }

3. Intervention — per-group threshold adjustment¶

The model produces a continuous score (in df.score). The current 0/1 prediction uses a global threshold of 0.50. We can ship per-group thresholds that pull the failing metric back inside the policy bound — at some accuracy cost.

In [10]:
def per_group_thresholds(df, subgroup_col, target_pos_rate):
    """Pick a per-group threshold so each subgroup's predicted-positive rate ≈ target_pos_rate.

    Args:
        df:               DataFrame with 'score' and subgroup_col.
        subgroup_col:     subgroup column to balance positive rates across.
        target_pos_rate:  shared target positive rate across groups (use overall positive rate).

    Returns:
        dict {group: threshold}. Each group's threshold is the (1 - target_pos_rate) quantile of its scores.
    """
    # TODO Step 1: for each group g, threshold = group's score quantile at (1 - target_pos_rate).
    # TODO Step 2: return {group: threshold} dict.
    thresholds = {}
    for group in df[subgroup_col].unique():
        subset = df[df[subgroup_col] == group]
        # Find the score that represents the (1 - target_pos_rate) quantile
        thr = subset['score'].quantile(1 - target_pos_rate)
        thresholds[group] = thr
    return thresholds


def apply_per_group_thresholds(df, subgroup_col, thresholds):
    """Return a new prediction column from per-group thresholds."""
    out = df["prediction"].copy()
    for g, thr in thresholds.items():
        mask = df[subgroup_col] == g
        out.loc[mask] = (df.loc[mask, "score"] >= thr).astype(int)
    return out

6. Launch Recommendation Memo¶

Recommendation: Conditional Launch

Rationale: The model fails the fairness audit on protected attributes. Before intervention, the model showed a Demographic Parity ratio of 0.792 for race (below the 0.80 floor) and an Equal Opportunity difference of 0.264 (far above the 0.10 ceiling). While the per-group threshold intervention successfully fixed the Demographic Parity issue (raising the DP ratio to 0.999), it failed to bring Equalized Odds (0.247) and Equal Opportunity (0.153) into compliance, meaning error rates remain unequal across racial groups. Because the model is currently making unequal mistakes that could cause real financial harm to minority groups, a full launch is not acceptable. However, a Conditional Launch is recommended because the intervention proves the model's outcomes can be mathematically adjusted. Launch is approved ONLY IF the following controls are implemented.

Recommended controls: 1-Deploy per-group thresholds: Implement the specific score thresholds calculated for each racial group (e.g., Asian: 0.539, Black: 0.474) to ensure demographic parity is maintained in production.

2-Human-in-the-loop review for denials: Because Equal Opportunity still fails (0.153), any loan application that is denied must be automatically flagged for a human loan officer to review before a final rejection is sent to the applicant.

3-Alternative mitigation testing: The Data Science team must test pre-processing techniques (like AIF360 Reweighing) to fix the root cause in the training data before the next retraining cycle.

90-day monitoring plan:

Metrics monitored: Demographic Parity Ratio, Equal Opportunity Difference, Equalized Odds Difference (sliced by race, gender, and age_band).

Cadence: Weekly for the first 30 days; monthly thereafter.

Owner: AI Risk Officer (with Data Science MLOps team).

Escalation: If DP Ratio drops below 0.80 OR EO/EOpp differences rise above 0.10 for two consecutive weeks, the model is automatically rolled back, and the AI Review Board is paged.

Key takeaway (do not edit): fairness metrics are inputs to a governance decision, not the decision itself. A fairness audit is incomplete without (a) intervention testing and (b) a launch recommendation. The deliverable is a defensible decision, not a metric table.

Reference Notes¶

A few specification details for the fairness-policy thresholds and library APIs used above:

  • 0.10 ceiling for equalized-odds and equal-opportunity differences. The 0.10 threshold used in the SafeWheels / UdaciBank scenarios is a firm-policy threshold chosen for this lesson, not a regulatory or industry-wide standard. Real organizations set EO / EOpp ceilings based on their policy, regulatory exposure, and the distribution of their training data; common firm policies range from 0.05 to 0.15 depending on use case and risk tier. By contrast, the 0.80 demographic-parity floor is anchored to the EEOC 4/5ths rule and has external regulatory provenance.
  • ThresholdOptimizer is post-processing per-group threshold optimization. It selects a separate decision threshold per protected group to satisfy a fairness constraint (e.g., equalized odds). It does not modify the training data — that's the role of pre-processing techniques like AIF360's Reweighing. Both families are valid mitigations; they intervene at different points in the pipeline.
  • The fairness-impossibility result. The formal impossibility result (Chouldechova 2017; Kleinberg–Mullainathan–Raghavan 2016) is between calibration and error-rate balance under unequal base rates. The "impossibility trilemma" framing across DP, EO, and EOpp is a related practical observation — these metrics generally cannot all hold simultaneously except in degenerate cases — but the formal proof targets the calibration-vs-equalized-odds pair specifically.
